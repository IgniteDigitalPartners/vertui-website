# SectionHeading

The eyebrow, bold lede and paragraph stack that opens most content sections on vertui.com.

**Consumer provides:** a container with `vt-heading` holding, in order, an optional `p.vt-eyebrow`, a heading with `vt-lede` (or `vt-title` for a 32px h2), and one `p.vt-body`.

- The eyebrow is uppercase `eyebrow` style in `jadestone`: short and declarative ("SCIENCE-POWERED GROWTH", "WHY CHOOSE VERTUI?").
- Use `vt-title` (`section-title`, 32px) for standalone section headings like "Join Our Mailing List"; use `vt-lede` (`lede`, 20px bold) when an eyebrow carries the label.
- Keep the stack at most 640px wide; body copy stays `body` in `blue-lobelia`.
